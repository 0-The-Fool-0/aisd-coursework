# Алгоритмы и структуры данных (АиСД)

[English version](README.md)

Коллекция самостоятельных лабораторных работ на C++ по дисциплине «Алгоритмы и структуры данных». Прежнее сокращение ASID заменено корректным названием **АиСД**. Лабораторные сохранены в отдельных каталогах с собственными решениями и проектами Visual Studio.

## Темы, встречающиеся в исходниках

- обработка последовательностей и массивов;
- линейный и двоичный поиск;
- операции над деревьями и проверка их свойств;
- поиск кратчайших путей в графах;
- матричные задачи;
- хеш-таблицы;
- отдельные алгоритмические задачи с текстовыми входными данными.

Названия папок и файлов намеренно сохранены близкими к оригинальным формулировкам заданий, чтобы можно было сопоставлять решения с лабораторными.

## Сборка и запуск

Для большинства заданий используется Visual Studio. Откройте файл `.sln` нужной лабораторной и собирайте её отдельно. Общего приложения и общей сборки для всех каталогов нет. Некоторые программы читают `input.txt`, `in.txt` или похожий файл из рабочей директории и записывают результат в `output.txt`.

В текущем снимке есть несколько пустых файлов-заготовок `FileName.cpp`; наличие проектного файла само по себе не означает, что задание завершено. Комментарии в некоторых старых исходниках могут отображаться с некорректной кодировкой. Эти файлы не переписывались в рамках обновления документации.

## Состав репозитория

Исходники, файлы проектов и необходимые примеры ввода сохранены. Артефакты сборки, исполняемые файлы и локальные настройки IDE следует исключать из Git. Сборка и тестирование всего набора не заявляются.

## Учебный контекст

АиСД формирует практическую базу по выбору структур данных, анализу алгоритмов и решению задач на графах, деревьях, массивах и поиске. Репозиторий — архив учебных реализаций, а не единая библиотека.
